Your Mac already ships over a thousand app actions. Hand them to Claude.

intents-mcp finds the App Intents your Mac apps and system frameworks expose and serves them as MCP tools to Claude, Codex or any agent. Public APIs only, no security settings to turn off.

How it works

Public APIs end to end

Index intents

Read the App Intents metadata each app publishes.

Choose tools

The user picks which actions an agent may use.

Sign a shortcut

Wrap each action in a shortcut and sign it with Apple's tool.

Add once

The user clicks "Add Shortcut" once per action (plus once for a read-back helper).

Serve over MCP

The agent calls the tool; intents-mcp runs the shortcut and returns the result.

Weekend scope

  • Swift CLI: list, enable, serve (MCP over stdio)
  • The simple tier first: actions with plain inputs that run in the background (47 on the Mac checked)
  • Inputs and outputs passed as plain JSON
  • Homebrew install

Left out on purpose

  • Anything needing private APIs or SIP off
  • iOS (later, through Shortcuts on iPhone)
  • A GUI app

Risks

  • Apple may ship this itself. MCP groundwork was found in App Intents betas, and OS 27 lets Siri hand requests to ChatGPT or Claude.
  • Manual steps per tool ("Add Shortcut", sometimes "Always Allow"), and most actions need entity inputs that Shortcuts won't take as text.
  • Few third-party apps ship intents yet. Signing needs an iCloud login, and Apple receives a copy of each shortcut.

Why this one

  • The best fit for your Swift and macOS skills.
  • Costs nothing to serve: everything runs on the user's Mac.
  • Limatum's Apple Events and Accessibility drivers can cover apps without intents later, with read-back checks.
